遊び方

■ 基本ルール

上から落ちてくるブロック（テトリミノ）を配置し、横一列を隙間なく揃えると消去されてスコアを獲得できます。
画面上部までブロックが積み上がるとゲームオーバーになります。

■ 操作方法（キーボード）

  • [← / →] : 左右移動
  • [↓] : ソフトドロップ (少し早く落下)
  • [↑] : ブロック回転
  • [Space] : ハードドロップ (一気に落とす)
  • [C / Shift] : ホールド (キープ)
  • [P] : 一時停止

■ 操作方法（スマホ）

画面下の「←」「→」「↓」「回転」「一気に」「HOLD」ボタンで直感的に操作できます。

■ 特殊機能

・ホールド: 出現中のブロックを1つ保管し、好きなタイミングで入れ替えることができます。(1ブロックにつき1回)
・ゴースト: 落ちる位置を予測した影が表示されます。
